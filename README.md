Code and data repository for the manuscript *Movement-informed projections of Bristol Bay red king crab distribution to support spatial management decisions* by Hardison et al., in press in the Canadian Journal of Fisheries and Aquatic Sciences. 

  
**Repository file structure**  
`R/` - data processing, analysis, and visualization scripts  
`figs/` - figures  
`data/` - data inputs and outputs. 

  
Please email [seanhardison@gmail.com](seanhardison@gmail.com) if you have questions.
